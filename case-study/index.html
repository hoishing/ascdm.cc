01Brand Context

已有產品與電商網站,卻缺少可衡量的成長節奏

客戶是台灣口腔保健領域的領導品牌,產品線完整、品牌認知度高,Shopify 電商網站已上線多年。但 SEO、內容、社群、電子報、影片各自為政:行銷團隊負責社群、業務團隊管產品頁、外部代理偶爾寫文章,沒有人把「搜尋需求」當作核心驅動力。

KPI 看得到 sessions 但看不出機會;看得到 impressions 但拿不出行動清單。客戶想要的不是更多的內容,而是一條可重複、可預測、可驗證的營運節奏。

一年內持續累積的內容資產規模

7 大主題內容中心,涵蓋產品教育與購買指南
200+ 關鍵字研究資料庫(Taiwan / zh-TW)
90+ 影片YouTube 標題、描述、章節、字幕

客製主題80+ blocks · 130+ sections · 140+ snippets
190+ 向量產品圖、說明圖、社群圖卡
500+ 圖片Shopify CDN-hosted、自動 alt text
月報自動化GSC + GA4 + Shopify + Ahrefs 整合

03Content Engine

一份關鍵字資料,驅動四種輸出

關鍵字研究是上游,內容是中游,分發到 newsletter、social、video、product page 是下游。Analytics 回流到關鍵字研究形成閉環。

內容生產一次,觸點四個渠道,KPI 一個閉環。

04Sample Deliverables

每個渠道都有可重複的執行範本

交付物不只「文章」或「報告」,而是可被下個月複用的範本與資料表。以下為各渠道代表性產出說明(去識別化)。

Pillar Article 結構範本

每篇文章包含目標關鍵字、Hero hook、Problem framing、結構化教學區塊、產品 CTA、FAQ schema、相關閱讀。

  • SEO title (25-35 CJK 字)
  • Meta description + Open Graph
  • FAQ JSON-LD schema(3 Q&A)
  • 內部連結至 supporting + product
  • Shopify CDN 圖片與 alt text

月報範本(GSC + GA4 + Shopify)

每月一份固定結構報告,讓客戶在 10 分鐘內看完現況、知道下一步要做什麼。

  • Executive summary 三段
  • GSC clicks / impressions / CTR / avg position
  • GA4 sessions / users / engagement
  • Backlink 新增與流失
  • 下月優化任務 + 責任分工

Shopify 客製主題

從零開始開發、針對 SEO 與內容呈現優化的客製主題,可隨內容戰略迭代。

  • 80+ 客製 blocks 與 sections
  • Blog cover-template 與 collection SEO
  • 結構化資料(Article / FAQPage / Product)
  • 圖片 lazy-load 與 webp 優化
  • Sitemap、canonical、redirect 流程

社群與 Newsletter 內容

每篇 pillar article 衍生 4-5 則社群貼文 + 1 期電子報,排程一次設定,每日自動發佈。

  • FB / IG / Threads 文案 + 圖卡
  • Shopify Email HTML 模板
  • GitHub Actions 每日 autodeploy
  • 跨平台 image map(CDN URL 統一管理)
  • 內容排程與重複利用追蹤

05Operating Cadence

每日、每週、每月各有節奏

不是一次性交付,是固定節奏。每個節奏都有明確產出與下一步行動。

Daily

每日

  • 3 社群平台自動發佈(GitHub Actions)
  • 內容上線監控與圖片 CDN 驗證
  • 緊急議題即時回應
Weekly

每週

  • 30 分鐘客戶 sync
  • 本週內容上線 + 下週重點確認
  • 關鍵字機會 + 內容缺口檢視
Monthly

每月

  • GSC / GA4 / Shopify / Ahrefs 月報
  • 內容戰略重排序與 hub 擴充
  • 下月任務清單 + 責任分工

06Outcomes

用等級描述的成效(非具體 KPI 數字)

為保護客戶商業敏感資料,以下用等級描述替代具體數字。實際成效依產業、競爭、預算與配合度而異。

FIRST PAGE

Search visibility

Primary commercial keywords 進入 Google 首頁,主要產品類別可被自然搜尋發現。

TRIPLE-DIGIT

Traffic growth

Clicks / impressions / sessions 月對月雙倍以上增長(early-stage 階段)。

FIVE-FIGURE

Content depth

核心 content hubs 月 impressions 達五位數量級,可預測的有機曝光。

DAILY

Operational rhythm

3 社群平台每日自動發佈,月報節奏穩定,內容供應鏈可預測。
